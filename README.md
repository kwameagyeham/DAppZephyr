DAppZephyr enables real-time, cross-chain data synchronization and auto-scaling for seamless, high-performance decentralized application gateways on blockchain networks.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DAppZephyr.git`
2. `cd DAppZephyr`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
